#  বাজার দর (BazarDor)

**বাজার দর (BazarDor)** হলো একটি সহজ ও ব্যবহারবান্ধব ওয়েব অ্যাপ, যেখানে বিভিন্ন পণ্যের বর্তমান বাজারদর এবং দাম বাড়া-কমার তথ্য সহজেই দেখা যায়।

## 🛠️ Technologies Used

* Next.js
* React
* Tailwind CSS
* Better Auth
* MongoDB
* REST API

## ✨ Key Features

1. 📊 **আজকের বাজারদর** — বিভিন্ন পণ্যের বর্তমান দাম দেখা যায়।
2. 📈 **দাম বৃদ্ধি ও হ্রাস** — কোন পণ্যের দাম বেড়েছে বা কমেছে তা দেখা যায়।
3. 🔍 **Product Details** — প্রতিটি পণ্যের বিস্তারিত বাজারদর দেখা যায়।
4. 🗂️ **Category** — Category অনুযায়ী পণ্য দেখা যায়।
5. 🔐 **Authentication** — Sign Up ও Sign In করার সুবিধা রয়েছে।
